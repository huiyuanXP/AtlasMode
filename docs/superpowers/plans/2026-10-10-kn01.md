## Global Constraints

- 作者是用户输入的显示署名，不是已验证登录身份。
- author 去首尾空白后 1–200 字符，text 1–20,000 字符（空白文本拒绝，合法正文保留原文），id 1–200 字符，revision 为正 safe integer。
- 默认 page=20，最大100；非负 safe offset，正 safe limit；升序 createdAt+id，history 按 revision 降序。
- orphan 锁存：首次明确缺失后，刷新不能自动恢复 bound，即使原 ID 又出现。
- text 编辑和显式删除不依赖源码存在，解除绑定不要求源码快照。
- 每次 mutation、CAS、历史及本项目 plan 失效均在同一同步 SQLite transaction；刷新批量转 orphan 时每条 plan 仅 revision+1。
- 已有 Approval 的plan-only semanticHash与approved-plan历史不可更改；新批准必须reviewContext.version=1/knowledgeHash且真实验证不可变approved-annotations，缺失/篡改failclosed，旧历史无上下文不可由当前注释补齐。
- 迁移DDL/journal_mode持久写前只接受empty/精确known001/精确known002；未知marker/schema/CHECK/kind/trigger/index/view拒绝且原DB文件/DDL/value字节不变。旧value以SQL原样复制rowid/kind/id/value，不JSON重新编码。
- 不迁移旧规划 annotate，不实现 KN-02 知识文件导出/导入、DATA-01 备份恢复、MCP/Agent allowlist 或目标源码写入。
- 保留 AGENTS.md dirty、其他 agent 修改、证据与记忆；无全局配置、key、session、无关服务/自动清场。
- 主任务协调所有共享入口的修改/检查/stage/commit/push，工作者只报路径和结果；不整仓 git add，不自行推送、merge 或部署。
- 若主任务后续明确授权 spawn：每次写明确 model、reasoning_effort、fork_turns=none；短简单 gpt-6.1-sol low，长简单 gpt-6-luna xhigh，其他简单 gpt-6-luna high/xhigh，复杂 gpt-6.1-sol high。无静默替换。当前不 spawn。
