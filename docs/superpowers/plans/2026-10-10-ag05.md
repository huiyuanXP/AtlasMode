# AG-05 Direct Responses Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans task-by-task. 主控协调一次独立安全审查；不擅自spawn。

**Goal:** 无 CLI 的服务端 Responses 流式模型与同项目 MCP 工具循环。
**Architecture:** 单轮适配器连接真实 scoped MCP SDK；SSE parser专门检查完整响应；现有Bridge管理运行与journal。
**Tech Stack:** Node24 fetch、MCP SDK1.32.0、TypeScript、Vitest。
**Spec:** docs/superpowers/specs/2026-10-10-ag05-design.md

## Global Constraints

- key仅server env；无登录/真实凭据读取/付费请求/源码执行写入/commit/push。
- 120秒/8provider请求/32工具/1MiB流与累计请求/256KiB工具结果；fixture测试可在可信构造注入更小预算。
- web/indexer不改；依赖锁版本保持；全根build先申请slot。

## Review Focus

- SSE分片UTF8/CRLF与缺completed应失败。
- function_call完整合法外项目参数应拒绝且revision不变。
- 草稿提交后cancel/error应保留journal，并阻止后续工具。
- hosted/native工具与伪造名称不得执行。
- HTTP错误/redirect/stream错误不得泄漏key/raw provider正文。
