# AG-05 直接 Responses API 设计（2026-10-10 UTC）

目标：管理员通过服务端环境配置模型 HTTP Provider，浏览器沿现有项目 Chat 使用真实 AtlasMode MCP 查询及未批准草稿，不依赖 Codex CLI。

采用官方 Responses SSE：相比另建 Chat Completions 转译，Responses 保留现代模型的工具调用与 reasoning continuation；相比远端托管 MCP，服务端本地工具循环可复用已审核项目网关，不暴露本地服务。首版只宣称 Responses 协议支持，兼容服务必须独立验证。

`CODEMAP_AGENT_PROVIDER=responses`、`CODEMAP_AGENT_MODEL` 必填；`CODEMAP_AGENT_API_BASE_URL` 默认 `https://api.openai.com/v1`；`CODEMAP_AGENT_API_KEY_ENV` 默认 `OPENAI_API_KEY`，其值是环境变量名。key 只从服务端环境复制；不读取真实认证文件，不写仓库，不返回密钥或 endpoint。HTTPS 必须；HTTP 仅允许明确 loopback fixture 地址。URL 禁止 userinfo/query/hash，禁止 redirect 跟随。status 仅说明配置可用，不触发付费探测，也不表示模型验证通过。

每轮创建真实 SDK Client/InMemoryTransport 与 `createMcpServer(gatewayUrl,{projectId,allowedTools})`。MCP 工具目录与 context allowlist 交集必须一致；独立固定规划安全目录再次限制，未知请求 fail closed。Provider 只收到 function schemas，不接受 hosted/native tools。参数由 JSON 解析及既有 strict Zod MCP schemas 校验，项目/plan 归属由 MCP 与网关双重校验。没有 shell、源文件写入、审批或项目打开工具。

`store:false`、`stream:true`、`parallel_tool_calls:false`、`max_output_tokens:4096`，保留完整 response.output（含仅服务端 encrypted reasoning）和 function_call_output 到下一 HTTP 请求。公开只发 output_text delta（及未出现 delta 的 final text），隐藏 reasoning 与原始参数/结果。工具只在完整 completed response 后串行执行，重复 call_id、异常 item、不完整/错误流拒绝。

预算：120 秒、最多8次 HTTP请求、32工具调用、1 MiB provider流输出、1 MiB累计请求内容、单工具结果256 KiB。无自动重试，避免付费及草稿重复。取消/超时 abort provider读取，停止排新工具，等待已开始的 MCP 调用与网关 journal 完成，再关闭SDK。超时/错误/取消都保留真实已提交草稿。

现有 AgentBridge 继续负责每项目/频道单轮、全局4轮、TTL、公共错误文案、项目轮次隔离。responses enum 为纯增加；web由其他owner集成显示。服务器选择受信任 factory；HTTP不能选择测试runner或凭据。

验收：本地 HTTP fixture +真实SDK/HTTP/SQLite覆盖分片SSE、工具草稿循环、外项目拒绝、未知工具、schema错误、凭据隔离、provider HTTP/stream错误、取消/超时、预算、并发、源代码sentinel。真实provider成功/错误/取消/并发/MCP闭环未授权本子代理执行，故整票 PARTIAL，fixture不替代真实模型。

自检：范围仅adapter及最小server构造/依赖；既有native保持；能力边界不是仅提示词；取消等待已转发写入；工具schema从真实MCP取得避免复制漂移；缺真实provider gate明确。依据已读取官方 [function calling](https://developers.openai.com/api/docs/guides/function-calling)（strict:false保留可选字段及reasoning回传）、[streaming](https://developers.openai.com/api/docs/guides/streaming-responses)（output_text.delta/completed/error）。遵循AGENTS自主例外，设计自检通过后执行，不提交推送。

独立审查修复：MCP API_TIMEOUT/API_UNAVAILABLE/API_INVALID_RESPONSE/INTERNAL_ERROR 或SDK transport异常属于执行结果不确定，停止后续provider/工具且由gateway.close等待在途journal。仅确定的输入校验/项目归属/版本冲突等已完成错误可继续。依赖DAG按主控授权增加server→mcp公共入口（mcp仅core），eslint.config.mjs保持其余边界，workspaces及dev先mcp再server。
