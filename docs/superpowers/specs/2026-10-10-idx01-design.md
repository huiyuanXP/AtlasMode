# IDX-01 bounded mutation design
Ticket: docs/tickets/IDX-01.md. Scope: indexer and independently named tests/evidence.
Root cause: select() discards first-property provenance on nested access; consumer writes invalidate the entire forwarding group, suppressing the default callable entry.
Decision: retain nested/dynamic provenance independently of call rejection. A known first-key deep write rejects ALL named exports across proven forwarding aliases, while preserving the default callable identity. A dynamic FIRST key, root namespace escape, cycle, or unsupported forwarding still invalidates the whole group. Same-module deep writes use the same named-export rule. Nested calls remain unresolved.
Why all named exports: self references, prototype.constructor and unknown holders can return to the root and overwrite another property. Avoid recursive alias inference and false edges by accepting false negatives for untouched named exports.
Safety: literal empty-string keys remain distinct from dynamic keys. ESM namespace .default maps to the CJS root as before. Existing SCC, depth, shadowing, mutable-binding and detached-exports guards remain. No new value flow/mixin/prototype-call inference/dependencies/public API.
Evidence: RED/GREEN default entry preservation and all named/deep calls rejection; first-dynamic/root-escape/SCC negative tests; complete clean Express dbac741a49a5a64336b70c06e85c2e2706e36336 HTTP/MCP/UI strict gate with full context pagination, source and PNG.
