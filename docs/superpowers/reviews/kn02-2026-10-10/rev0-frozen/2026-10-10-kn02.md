# KN-02 Knowledge Transfer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task after main authorizes a product window. 独立审查及模型/槽位由主控安排，当前禁止 spawn。Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 提供带 schemaVersion 的知识包导出与校验，以及真实冲突预览、分域显式应用，保留历史批准和源码。

**Architecture:** core 管纯协议/预算，service 管 export/preview/CAS/DB batch，目录批量复用 POL 队列与持久 intent。数据库域与目录域分别确认，第二域必须重新预览；UI/MCP 共享 service，MCP 只读。

**Tech Stack:** Node 24.19.0 / npm 11.9.0 workspaces，TypeScript/Zod，SQLite StoragePort，React/Vitest/Playwright，既有 MCP SDK，node:crypto SHA256/HMAC。

**Spec:** [2026-10-10-kn02-design.md](../specs/2026-10-10-kn02-design.md)

## Global Constraints

- 当前 DESIGN ONLY：只写此计划、spec、own ledger；不源码、不 build/test/DB/stage/commit/push/spawn，不更新票 DONE 或 root 状态。
- 真正实施前主控授权各共享文件/构建窗口；首用、GRP02、FS/KN/POL/IDX 等既有行为保留，接口按重新读取的冻结实现接线。下列新路径为拟创建，不假称现有。
- 不执行知识包、不改源码、不造事实、移动函数或写规划；知识导出不是 DATA01 全 DB 备份。历史批准/context/registry/history 禁止导入覆盖。
- 每域 ≤100 动作；包 ≤4 MiB、depth ≤32、JSON values ≤250000、总项目数 ≤1000；MCP ≤64 KiB；POL before/candidate 各 ≤1 MiB；预览20/max50项且JSON≤64 KiB；token10分钟/≤16 KiB；每域receipt≤256 KiB，预算参数只能收紧。
- annotation 沿用 KN01严格20k/200/200/revision约束；新便携组 title≤2000/description≤20000/成员≤200；repo-relative path≤2048。不改旧持久组上限或 strip 未知内容。
- 同项目用 POL 原队列；同步 SQLite transaction 内无 await；DB域实质变化一次 invalidate，目录域一次 finalize/invalidate；混合包分别结果，第二域真实新预览。
- UI 创建 source=user，包 provenance 不替代本地身份；replace 保留 source；全部成员/reference 显式映射真实当前 domain ID，alias/temp/计划入口不接受。
- 本计划不包含 commit/push。即使上游 skill建议 frequent commits，用户/主控当前契约由主控审核后独立执行。

## Review Focus

1. 相同 origin ID 在别项目/快照出现、orphan 重现、墓碑不能复活：Task2/3 负例 fail closed，保留未提交预览。
2. 输入包伪造 history/context/legacy registry、future schema、duplicate key/过深/过大：Task1/3 原字节不变断言。
3. stale token、审批/计划并发、刷新后成员变化、相同 mutationId 不同 payload：Task2/3/4 重读 CAS、冲突或既有收据，绝不二次失效。
4. POL rename 后 finalize 故障/第三文件、unknown 字段和 DB-only 迁移：Task4 持久 fault/restart 原始证据，不能声称全包 rollback。
5. 真实 UI 部分成功、第二域取消/重新预览、项目切换、MCP 输出预算：Task5/6 真点击/SDK/SQLite验证，不隐藏入口或换纯 API 验收。
