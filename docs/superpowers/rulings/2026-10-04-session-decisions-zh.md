**Rulings I made**

1. 首轮按问卷增加 Python、多项目切换、英文、分组、目录约束和历史。 代价：若范围理解偏差，需要可回退的模型和界面调整。

2. 无人值守期间继续执行，自检和独立审查取代逐阶段人工等待。 代价：默认选择与用户偏好不一致时，需要返工；不包含发布授权。

3. 使用云任务已有隔离 checkout，不再创建 worktree。 代价：修改留在本地 work 分支，需要用户之后选择整合方式。

4. 顺序执行 SDD，每任务新实现者和独立审查；实现者不另派助手。 代价：增加审查等待和上下文成本，保持单一实现所有者。

5. call_chain 后续步骤必须引用上一节点到当前节点的真实 resolved 调用；walkthrough 的可选关系必须接触对应节点。 代价：较宽松的旧 Agent 路线会被拒绝，需要重新提交。

6. 创建规划可指定基线；MCP 提交规划必须指定基线，拒绝不一致。 代价：旧调用方可能需要增加基线参数。

7. 批准和核对先实际刷新；MCP 读取当前批准也先刷新，网页普通浏览仍显示上次索引。 代价：增加索引延迟，并需要适配异步 service 调用。

8. 源码读取由 indexer 的可选 readSource port 负责；service 只委托。 代价：注入式 indexer 适配器可能需要新增读取方法。

9. 实际索引/存储的生命周期集成测试放在根 tests/integration，保持 service 的依赖边界。 代价：仅影响测试归属位置。

10. indexer 包显式包含 dist 和 Python helper，确保打包后可运行。 代价：需要随包结构更新清单；没有新增依赖。

11. 快照 ID 同时包含稳定分析结果/诊断/覆盖，源码 contentHash 保持字节摘要；观察时间、Git 和根目录不参与事实身份。 代价：解析能力变化时基线和路线需要刷新；历史快照保留。

12. 分页/预算图查询放在纯 core；上下文50/200，子图80/300节点、关系3倍预算；入口为最多50个候选。 代价：未来调整分页或预算时需要同步客户端契约。

13. Python 默认入口只使用公共顶层定义；TS/JS 使用显式导出，均标注候选依据。 代价：部分公开类方法需要通过类或搜索进入，未来可增加框架证据。

14. dev 启动器直接运行固定 TypeScript CLI 构建五个前置包，拒绝不符合已知脚本的配置。 代价：未来自定义构建脚本需要明确更新启动器。

15. MCP 增加分页 list_projects 和仅创建 Agent 来源的 propose_group，仍由共享 service 验证。 代价：增加两个适配工具契约；高级分组操作另行实施。

16. 拆分导航与规划面板，保留负责请求生命周期的协调控制器。 代价：未来界面变更可能需要调整组件参数。

17. MCP 操作明确检查 project/plan 所有权；提交规划为创建后更新，失败返回保留草稿 ID/revision；列表明确总量和截断。 代价：部分失败可能留下需要清理的草稿，响应契约可能需要扩展。

18. 有意义的分组/目录约束修改与该项目所有当前规划 revision 提升、恢复 draft 在同一事务中完成；历史批准不变。 代价：重新确认较保守；历史知识上下文仍不能完全重建。

19. 分组成员每页20个，用已有 context 查询、并发4；404 和其它失败分开，失联注释以 service 的 operationIndex 为准。 代价：每页有多次请求开销，必要时再增加批量元数据接口。

20. 保留约646行的项目/请求协调器，把历史、成员读取和面板职责放在专门模块。 代价：未来出现实际耦合时再做局部提取。

21. T07 的非阻塞语言提示问题带入相关 T08 修复，整体验收前必须解决。 代价：在 T08 完成前不能宣称问卷完整通过。

22. T08 改接候选纳入已加载、同快照的入口/搜索事实，并保留 service 验证和可读端点。 代价：可能需要修复候选生命周期或端点呈现；必须回归测试。

23. 接受整体审查四项重要及两项小问题，集中修复后只做一次针对性复审。 代价：更保守的未知、警告和本地代理限制可能需要局部适配。

24. 为快照增加可选扫描可用性，旧数据继续可读；缺失证据不当作删除成功。 代价：部分核对更保守，新事实指纹可能使旧基线需重新确认。

25. 区分默认排除目录和范围内不可用文件，避免依赖/Git目录使所有删除无法判定；开发代理由启动器显式启用。 代价：以后可能需要细化可用性分类或本地代理配置。

26. 采用受限捕获配置和内存编译器，JSONC 相对继承与最近 tsconfig 管辖。代价：覆盖偏保守；输入 hash 升级使旧基线需重新确认。

27. 种子算第1层，允许第16层、拒绝第17层；每条选中继承链独立验证。代价：边界约定可能需调整，不能用其他种子的已捕获文件绕过拒绝。

28. 被忽略、不可读或链接的最近配置作为 opaque scope，不回退祖先；用内部诊断标记传递。代价：未来可能需增加明确的内部类型。

29. 配置闭环后优先修复已复现 CommonJS 误判，再做 workspace 映射。代价：延后跨包覆盖，部分 CJS 暂显示未知。

30. 解析器改变后新增一次固定 Vite 产品验收，保留旧证据、不重复未改变的 Flask。代价：额外验收时间和新诊断需明确边界。

31. 已通过的后端配置生命周期记录真实 GREEN，缺失 UI 提供 RED。代价：后端没有初始失败，但避免人为制造错误。

32. 后续整体审查从已审查 MVP 归档基线开始，不重复派遣旧任务。代价：跨旧代码的交互可能需要针对性检查。

33. 逐项处理整体审查的33项未判定行为，保留 CJS 缺陷与所有未运行的平台、客户端、CI、恢复限制。代价：未支持行为仍需人工检查或后续修复。

34. 颜色修复保留 NO_COLOR，仅提供可移植启动方式，不改依赖、预加载或全局环境。代价：Playwright worker 强制颜色时警告仍会出现。

35. 唯一限定复审后将残留颜色警告保留为非阻断宿主债务。代价：噪声可能掩盖将来的警告，因此保存原始日志与明确状态。

36. 先做捕获 AST CommonJS 安全及小范围稳定入口，不执行 require，不做转发、值流或 workspace exports。代价：覆盖保守，v3 hash 使旧基线需刷新，历史和函数ID保留。

37. .cjs/.mjs 按扩展名确认格式；普通 .js 需要捕获的有效最近包，拒绝根外读取或祖先回退。代价：依赖根外配置和自定义 loader 的项目需人工补充。

38. 已知属性变更逐项拒绝，逃逸、未知计算键或身份损坏拒绝整模块；跨消费者及 ESM 导入共同校验，不做 module.exports=require 转发。代价：真实别名或旧式代码也可能显示未知。

39. 包配置按整份捕获字节计算新鲜度，包括无效内容和空白，而不是只看 type。代价：无关字段或排版修改也可能使规划/路线过期，需要重新确认；历史和函数 ID 保留。

40. 保留命名空间逃逸规则；Express 整仓库的自动入口标准未通过，实际浏览通过分别记录，后续单独处理静态转发。代价：转发入口暂需手动搜索；放宽规则会重新产生跨消费者误判。实际源码行为第36行，旧简报第37行已纠正。


41. Task3限定修复范围包含一次退出路径定因及有证据支持的生命周期修复，并提取重复浏览器拦截逻辑；不延长退出超时。代价：只修测试可能遗漏用户退出问题，无依据改服务可能影响持久化，因此需定因和独立复审。

42. 单独观测退出正常后，仅追加一次原并行条件下的带观测运行，最多检查这两种条件；不延长超时或称原故障已修复。代价：多花一次运行仍可能无法定因，罕见退出风险需独立审查而非反复重试。

43. 仅允许一次规划浏览器检查与 npm test 同时运行，以检查尚未重建的原负载条件；不重复构建、类型检查、目标浏览或压力循环。代价：再花约30秒仍可能无法复现，成功结果也不能证明原故障已修复。

44. 第四轮换全新 Astra 并提高推理强度，仅用小型真实服务测试检查未完整 HTTP 连接的退出风险；不把新类别当作原原因。代价：可能花时间发现不同问题，过度断连会影响完成中的操作，因此需真实失败证据、安全修复和限定复审。

45. 修复实际复现的未完成 HTTP 连接退出卡住问题，仅清理没有完整待响应请求的连接；用延迟完整请求、部分流水请求和重开 SQLite 验证保留数据，再顺序运行最终检查。代价：错误判断请求状态可能丢响应或提前关库，须精确保留测试和独立复审；原故障仍不冒认同因。

46. 五轮复审后，把首次未观测关闭失败保留为真实、未解决的 Important 历史证据缺口；当前已复现类别修复和440项测试有效，继续整体验收，不猜测第六轮修复。代价：原超时可能属于另一条罕见退出路径并再次发生；需用户审阅或遇到新证据后另票调查，原生信号和平台仍未验证。

47. 接受整体审查发现的循环加载绑定误判和环境文档过时，交给一个实现者集中修复，再做一次限定复审；不把静态转发或历史超时猜测塞进修复。代价：过宽循环拒绝会隐藏可安全运行的调用，过窄仍会误连；需真实失败、正反例和改后全项目检查。原超时及宿主警告继续保留。

48. 逐项裁决整体审查的51项保留行为：只接受已有范围内的证据，保留 Express 原入口失败、旧目标的历史阶段和所有未跑的平台、真实客户端、远端CI及云恢复限制。代价：每项仍可能需要补证或人工处理，具体负责人和成本已写入逐项记录。

50. 唯一整体复审后保留宿主颜色警告为非阻断 Minor，不改库、预加载、全局环境或过滤日志。代价：噪声可能掩盖后续诊断，需支持的上游或运行器维护。
